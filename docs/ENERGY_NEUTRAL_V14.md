# 機構の中立点と、足姿勢で変わるエネルギー中立点

2026-11-13。ユーザー確認の「エネルギー的な中立点」は、足姿勢に依存するポテンシャル最小点、すなわち復元トルクの符号が切り替わる点を指す。本書はその幾何学的診断である。**現在のv14出力制御は名目円弧Uを使用しており、ここで求めた移動中立点を出力へ適用していない。**

## 区別する量

- 機構の中立角 `theta_m=0`：機体の幾何学的な正立を表す観測座標。足が振れても、これを足ごとにIMUバイアスとして書き換えない。
- エネルギー中立角 `theta_E(beta_L,beta_R,pitch)`：足姿勢を一時的に固定したポテンシャル `U(theta,beta_L,beta_R,pitch)` の安定最小点。滑らかな所では `dU/dtheta=0`、接触切替の角では左右の傾きが最小を挟む条件で定義する。復元トルクは `-dU/dtheta`。
- 支持切替角：左右足の最下面高さが等しくなる角度。上の最小点と一致する場合もあるが、定義は異なる。
- エネルギーの数値原点：Uへ一定値を足し引きする自由度。これは最小点や復元トルクを移動させない。「U=0の点を変更する」ことと「安定平衡が動く」ことは異なる。

足が前へ振れると、機体が同じ角度でも接地を維持するための機体高さが変わる。したがって機構のゼロを通る途中で既にポテンシャルの谷を過ぎ、再び上りになることがあり、左右を同じ振幅へ調整するだけでは説明しきれない。

## 今回計算できたもの

出典は提供GLB `rw_walker_uploaded_assembly.glb`、SHA256 `63be3da5c06b9f198a3d6409b4b0a68ead9c2a638d87f06e7914c40b13693884`。既存の `tools/generate_cad_support.py` と `analysis/2026-11-11-walking/analyze_cad_support.py` と同じ上部X軸ヒンジを用いる。ヒンジのGLB座標はY=-17.578536mm、Z=82.825357mm。足メッシュは05/07。

全質量を機体固定の一点へ集中させる仮定を置き、質量0.1997kg、重力9.80665m/s²、基準重心高さH=120mmを使った。ヒンジから重心への位置は仮にX=Y=0とし、Zは `H-support(neutral)=37.174236mm` へ合わせる。足と脚の移動による重心移動は未同定である。

`R=Ry(theta)Rx(pitch)` とし、足メッシュをヒンジまわりに `Rx(beta)` で回す。床への非貫入に必要なヒンジ高さと重心高さは次のように計算する。

```
support = -min(all transformed foot vertices z)
z_CG = support + [R * c_body]_z
U = m*g*(z_CG - fixed_reference_height)
theta_E = argmin_theta U
```

固定した足姿勢での曲線を比較するため、図では各曲線の最小値を引いた。この図示用の原点を、動いている足のオンライン総エネルギーへそのまま転用しない。足姿勢ごとに引く定数を変えると、時間変化するエネルギーの式へその微分が入り、足からの仕事を隠してしまう。

## GLBの粗いポリゴンをそのまま転がしてはいけない

足裏円弧の主要な下側輪郭は、GLBでは4点の円弧標本と、それを結ぶ粗い弦になっていた。右足のX座標は約5.998、19.519、32.889、45.998mm。この4点を円へ当てはめると半径150.000006mm、最大半径残差0.000000159mmで、名目の150mm円弧と整合する。

元メッシュの弦を接触面として使うと、足が揃っていても±4.5度付近などに偽の極小ができる。今回の走査範囲では滑らかな円弧再構成との差は最大0.30003mJに達した。これは接触面の離散化による差であり、実機に複数の谷がある証拠ではない。

そこで診断では、4点に整合する円弧を各足801点へ再構成し、元メッシュと別に比較した。実物の面がこの滑らかな円弧であることは、STEP/現物の面でも照合する必要がある。生成済みファームウェアの頂点や接触方策は変更していない。

## 条件付きの数値例

すべて**CAD角**の例で、左足0度、機体前後姿勢0度、H=120mm、重心X=Y=0の仮定。カメラの前振りプラスは確認済みだが、カメラ相対ゼロとCAD絶対ゼロの一致は未確認のため、そのまま実機角へ対応させない。

| 右足CAD角 | エネルギー中立角 theta_E | 中立点から機構ゼロまでの位置エネルギー増加 |
|---:|---:|---:|
| 0度 | 約0度 | 約0mJ |
| 1度 | -2.25857度 | 0.64620mJ |
| 2度 | -3.95940度 | 1.37631mJ |
| 4度 | -6.26106度 | 2.70323mJ |
| 6度 | -7.86158度 | 3.86091mJ |
| 8度 | -9.05303度 | 4.85110mJ |

これらの対称な重心仮定ではエネルギー中立角と支持切替角が一致した。左右両足を同じ4度にすると中立角は約0度に戻るが、機体全体の高さは変わる。左足だけ4度では中立角は約+6.26106度となる。

定義を同一視できない例もある。H=140mm、重心X=-2mm、機体前後姿勢+2度、左0/右4度では、エネルギー最小角は-6.26349度、支持切替角は-5.74787度で、約0.516度異なった。H=100/120/140mm、重心X=-2/0/+2mm、前後姿勢-2/0/+2度の27仮説では中立角は約-6.26349〜-0.16663度へ変化する。これは実測の誤差限界ではなく、未確定の条件への感度である。

位置エネルギー増加の数値は、足をその姿勢に固定して谷から機構ゼロへ動かす場合の値である。実際には足が戻る間に地形そのものが変わるため、この表のJをそのまま必要モータ仕事にしない。

## 現在の経験的エネルギー制御へ混ぜる前の条件

現在のv14受動到達式は、観測された次ピークを**名目U**へ変換して回帰している。足/ホイールからの交換も条件付きの到達式へ含まれる。その式を維持して、現在の姿勢エネルギーだけCAD補正すると、原点・予測対象が揃わず、足の寄与を二重計上する可能性がある。

次の実装で扱うなら、機構角と中立角を別フィールドにし、足角の撮影時刻・受信時刻・現在推定時刻を保持して、`U(theta,foot_pose)` とその傾き、中立角、到達したい経路の最大Uを一貫した座標で計算する必要がある。単に `U_nominal(theta-theta_E)` へ置き換えると、足で変わる曲率や障害高さを捨ててしまう。

必要なエネルギーは、固定した足なら到達経路上の `max(U)-U_current` と現在の運動エネルギー、損失から考える。足が動く場合は `dU/d beta * beta_dot` の仕事交換も生じる。移動座標の角速度 `theta_dot-theta_E_dot` をそのまま物理的運動エネルギーへ代入するのも、追加の移動座標項なしでは適切でない。

現時点で根拠が揃っているのは、**機構ゼロとは別の中立点と地形を計算・記録する診断**までである。能動出力へ採用するには、少なくともカメラ/CAD角ゼロ、機体前後姿勢、実機の重心/足質量寄与、滑らかな足裏面を確かめ、次ピーク/目標も同じUで再計算して受動到達・入力仕事モデルを再照合する。新しいログで中立点付近の復元方向と減速/折返し位置を比較する。現行名目Uをこの移動中立モデルと呼ばず、診断結果と実際に使った入力方策を分けて残す。
