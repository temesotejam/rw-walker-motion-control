# 足の初回戻りと出量を使う試験版v13

2026-11-13。環境 `atoms3cam-foot-support-transfer`、build ID `foot-support-transfer-v13`。v12環境と配信ページは保持する。実機へは今回まだ書き込んでいない。

## 変更の目的

v12試行611622951では、右足7.013→6.837→5.836度の2区間連続減少が届くまで待ち、28.858秒に56 msを実行した。この間に機体の内向き速度は約31→13度/sまで低下した。補助後は中心を僅かに越えるだけで、次の十分な揺れや足の交替へ続かなかった。

v13は、大きな前振れの最初の小さい戻りを別の限定根拠で早めに使い、足量に応じて通常入力へ短い幅を加算する。これらは必要仕事が同定できた制御ではなく、記録と比較が可能な試験条件である。

## 最初の戻りを使う条件

既存のHistory、続いて2区間連続ReturningのLocal採用は維持する。これらに加え、局所3点のうち「大きい上昇の次に初回の小さい減少」が見えた場合をsource3 `local_first_turn` として扱う。Returning確定とは区別し、履歴score0を増やさない。

- 直前上昇が1度以上、今回の減少が0.15〜1.5度、減少速度1.5〜20度/s、直近画像間隔60〜150 ms。
- 主な前方足がTurningで、他足は局所Stationary。画像年齢100 ms以下、同run/同frame、画像有効・足ゼロ確定・両足有効/範囲内が前提。
- 観測された足角度をそのまま使用し、頂点を越える外挿をしない。初回戻り用の内部marginは `0.45+0.5×減少量+0.002×画像年齢ms`。これは真誤差の上限や接地の保証ではない。
- marginを引いた前方量3度以上、左右差2度以上。両足margin0.75度以下。
- 実制御では機体が中心へ向かい、距離2〜5度、内向き速度12〜40度/s、通常drive提案がある時だけ。coastをdriveにする用途や、ETA250〜500 msの失速経路には初回戻りを使わない。

小さい反転をノイズと取り違える可能性は残る。この限定条件の追加は、Returningの信頼性を向上させたという意味ではなく、足が大きく出た位相での早い入力を試す別経路である。旧v12のselect呼び出しはこの経路を許可せず、既存動作を維持する。

## 足量による幅の加算

通常driveの場合、両足の内部marginを引いた最大前方量をf、左右差の下限をaとする。`f>2度 && a>=1度` の時、加算幅は `2×ceil(f-2)` ms、最大12 ms。通常生幅との合計が80 msを超えないようにする。履歴/局所Returning/初回戻りのどの採用根拠でも、この追加条件を満たす場合だけ加算する。

この2 ms/度という設定は今回の限定試験値であり、足形状から求めた必要トルク・仕事量ではない。電流指令は通常と同じ1200mA。パルス幅と実電流積分/機体への仕事は線形と仮定しない。

通常提案に既存のtaper/trimを一度通した生幅を保存する。通常幅と加算後幅を車輪ガードのコピーで別々にpreviewし、backendでは同じ通常生幅へ保存した加算だけを加え、実車輪ガードを一度だけ通す。再taperやガード迂回はしない。実幅がpreview/要求幅と違う場合、幅を変えて出すのではなく不採用とする。通常生幅/加算後生幅/要求保護後幅/実幅を区別する。

coast支援15 msは増量しない。通常driveの生幅と要求保護後幅はともに80 ms以内。v12の静止/外向き拒否、画像160 ms制限、内向き6〜45度/s、足量下限、通常ZERO優先、同一ピーク一回、曖昧な書き込み時の停止を維持する。送信直前5 ms以内の再判定に備えて、候補時には幅+25 ms以上の一定速度中心所要時間を要求する。送信直前にもsource/足量/機体位置/幅を再評価し、条件が変われば送らない。実際の接地・通過時刻を保証する式ではない。
