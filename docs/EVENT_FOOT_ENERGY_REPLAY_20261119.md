# ZEROの前後にどう仕事を配分するか

2026-11-19。11月17日のv37歩行試行2件を元のRWLOGから再変換し、エネルギー制御v19で実行された戻り補助10件を再生した。1回目は後方転倒、2回目は胴体が前に傾いてESTOPになったという実験者の観察を使った。今回の変更はPC上の解析。

**現在のモデルでは、ZERO到達前の仕事を維持したまま短くできた補助は0/10件だった。** ZERO前と後の不足率を均等に扱うと7件で短縮案が出た。選択保留が3件あり、うち1件は後方転倒前の最後の補助だった。短縮して歩かせた実測はない。

## 各判断で見えていた足と、その後の実測

16.508 sと17.323 sでは、比較に使える同方向・同目標の過去の通常ZEROがなかった。保留は0 msの指令を意味しない。14.518 sの指令は26 ms、実経過は27 msだった。CSVには指令幅と実経過の両方を収録した。

ZEROと反対側ピークの両方を観測した8件すべてで、ピークはその時点の目標6.5°または7.0°を下回った。ZEROで主入力が実行されたのは7件。19.533 sの補助後は2.367秒たってZEROを通り、主入力なしで1.04°まで振れた。この周期には48 msの入力枠が残っていた。**時間を取り置けること、ZEROに着くこと、そこで有効な主入力を選べることは、それぞれ評価する必要がある。**

## 二つの終端で分かったこと

- **1回目、10.693 s。** 左足の直近5画像は19.41 → 18.51 → 17.86 → 18.04 → 18.09°。画像の終盤は小さく増加した。胴体の前後角は開始姿勢から+0.49°、角速度は+25.93°/s。実際の補助70 msで残り枠10 ms、局所の推定不足0.0146 mJ。足の位相を保留し、計算だけ比較すると、38 msに削る案では局所不足が0.2002 mJに増える。実機は判断の206 ms後にESTOPした。
- **2回目、23.412 s。** 左足は14.40 → 14.35 → 14.31 → 14.20 → 13.97°と戻っていた。胴体前後角−0.41°、角速度+6.78°/sで、その瞬間は開始姿勢に近づく向きだった。後に前方へ傾いて停止した事実をこの判断に持ち込まなかった。記録幅53 msでは前段要求0.1830 mJに対して予測仕事0.1850 mJ。それでも317 ms後のESTOPまでZEROは観測されなかった。26 msにすると残り枠は27 → 54 ms、前段不足は0 → 0.1323 mJ。過去のZEROを代入した後段不足は0.4468 → 0.3462 mJになる。どちらもモデル値であり、この試行の実測仕事や、候補入力後の運動を示す値ではない。

## 比較方法と妥当性

1. **各判断時点の情報を再構成した。** エネルギー判断51件と86件を、同一ピーク・方向の制御記録に対応付けた。制御演算前のマイクロ秒時刻までに制御側が実際に受け取った画像を使用。後から届いた画像は除外した。10件の選択フレームは本体が保存した整数msの画像年齢とも一致した。画像時刻から今回の演算前時刻までは26.7〜48.4 ms。足の位相は各足最大5枚の連続した過去画像から求めたもので、判断の瞬間の足先位置や接触の直接観測ではない。胴体には同じ制御判断に保存された前後角とバイアス補正済み角速度を使った。
2. **イベントで区切って仕事を比較した。** 前段は現在から機械的ZEROまでの局所的な要求仕事。後段はZEROから反対側ピークまでの要求仕事。共有する入力枠は80 ms。前段の候補を0 msから元のガード済み幅まで1 ms刻みで計算し、電流の立ち上がりから電荷と予測仕事を求めた。元の指令幅で本体記録の予測仕事を再現した最大差は0.001 µJ未満。
3. **後段の需要には、判断より前に終了した同一試行・同方向・同目標の補助なし通常ZEROを使った。** 直近3秒・最大3件とし、この2試行で使えたのは各判断0件または1件だった。3秒は過去事例の有効期間で、将来のホライズンは次のZEROと反対側ピークで終わる。事例側も記録済みのガード幅を上限とする。比較できた5件で、過去事例と、のちの実際のZEROで制御器が計算した仕事要求の絶対差は平均0.121 mJ、最大0.271 mJ。同じ過去事例を再利用した判断を含む。
4. **配分候補は、通常は前段と後段の要求に対する不足率の大きい方を最小化する。** 前に出た足がなお前振れ中で、胴体が開始姿勢から離れる速さが20°/s以上なら、後段の不足を優先して減らす仮説も実装した。この組み合わせは今回0件。短縮7件はすべて通常の配分計算による。足の出た量は先行足・左右差の判別に使った。足角何度が追加で何J必要かという関係、あるいは前後姿勢による転倒境界は同定していない。
5. **別の比較では、ZERO前に払える仕事を先に確保した。** 現行入力で前段要求を満たす場合はその要求を、満たせない場合は現行入力で払える分を確保する最短幅を求めた。10件とも記録幅と一致した。全件が負方向への戻りで、補助時の左右揺動角速度21.58〜32.82°/sは同方向の仕事モデルの同定範囲35.74〜91.49°/sを下回る。7件の実行済みZERO主入力も、モデルの少なくとも一つの同定条件から外れていた。

## 実機への判断

今回の結果から優先するのは、**足が出た状態で、現在の揺れと残りの入力から機械的ZEROに届くか**の見積もりである。現行の局所仕事要求を満たした計算でも、2回目の最後にはZEROを観測できなかった。足姿勢ごとのエネルギー的な中立点（位置エネルギーの谷）や低速での有効仕事を同定し、ZERO到達の余裕を検証する価値がある。機械的ZEROは今回照合した胴体角0°として保持できる。各候補の前段の余裕とZERO後に残る主入力を同時に記録すれば、どちらの見積もりが実際の半周期に合うかを確かめられる。

この解析は記録軌道上の1判断ずつで候補を比較した。候補選択後に過去の軌道を別の入力で進めるシミュレーションや、将来の足運動を解く閉ループMPCの検証は行っていない。反対方向への戻り補助、実際の接触・滑り・前進量、転倒予防への効果も今回の判定範囲外。
