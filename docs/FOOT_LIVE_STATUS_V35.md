# カメラ処理とWeb通信の競合を減らすv35（2026-11-17）

## 変更の目的と範囲

v34のUSB停止測定では、通信なしで約37.8 Hz・中央値約25 msだった一方、毎秒5回の詳細状態取得では約32.6 Hz・p95約47 msとなった。今回は画像取得設定・検出器・26 ms観測周期・エネルギー制御を維持し、通常画面更新の生成量・送信量を減らす。

`atoms3cam-foot-live-status` / `walking-foot-live-status-v35` はv34を継承する。対応を示す `live_status_supported:true` を受信した画面だけが、次回以降 `/status.json?view=live` を使用する。初回・強制更新・旧版では従来の `/status.json`。通常更新の頻度は変更しない。旧画面からの詳細取得も引き続き可能。

軽量応答でも姿勢、電流、足の最新観測、実際の校正範囲、ゼロ点、開始条件、コマンド、転送状態、起動ID・run IDを保持する。校正表、内部受信・先行計算カウンタ、詳細camera/memory/controlを省略する。動的状態を以前の応答と合成せず、新しい応答で置き換える。未知のviewは詳細応答になる。

診断保存は表示時点のキャッシュと鮮度をそのまま保持し、詳細取得ができれば別の `device_detail` に保存する。`detail_fetch.same_boot/same_run` で別起動・別試行を区別する。失敗してもキャッシュを保存し、測定のオフライン期間・転送中には追加要求を送らない。診断取得中は通常pollと開始ボタンを抑止する。取得期限は2.5 s。

足ログ1600件・メタデータ容量などはv34のまま。モータ操作・歩行測定は行わない。

## 実機と検証

- COM7、MAC F0:9E:9E:32:53:0C、バッテリー切離しUSBのみ、立位。
- 書込み後の実ID v35、boot2671814620、motor0/command submitted0/pendingfalse、左右検出・ゼロ点確定を確認。
- ビルドSUCCESS202.524 s、app1956784 bytes、SHA256 `caa02acacf3b6e579b672b93dd52d577332241f12a41f5bee59c81851c5ed482`。実HALリンクと専用配信8ファイル一致。
- 実機JSONで詳細応答がv34の全ルート/footキーを保持すること、軽量化の除外キー、校正範囲一致、未知viewのfallbackを検証。実際の詳細・軽量JSONを製品JSへ渡し、左右角表示と起動IDの採用を確認。
- 製品JSで対応検出、最新値置換、開始ゲート、旧版切替、診断時の別起動・別run隔離、取得失敗時キャッシュ保存、オフライン/転送中の通信抑止を検証。既存UI/オフライン/診断鮮度/ログ再開・CRC・キャンセル/足範囲テスト、19インストーラ構成、埋込み一致PASS。
- 診断保存が非同期になるため、既存exportテストの保存クリックをawaitするよう変更し、再実行PASS。初回失敗は保存完了前に結果を参照したfixtureであり、無視して通過扱いにしていない。

実送信サイズの例は詳細6866 bytes→軽量3818 bytes（44.39%削減）。先の9.7 KBという説明は整形して保存したJSONサイズと混同していたため訂正した。数値の桁数によって応答長は変動する。

## 測定条件

同一起動で45 s区間を比較する。ヒストグラムは初回制御受取り全件、0.25 ms幅、露光時刻未校正。通信なしはstatus/previewカウンタ差分0で確認。負荷比較は両viewとも約5 Hzの同一要求頻度で行い、外部要求・再起動がないことを確認する。歩行中の精度や20 ms達成をこの静止測定から推定しない。

要求間隔は200 ms指定だが、ネットワーク応答・ホストスケジューリングで実回数が異なる（上記区間は約4.67〜4.91 Hz）。全件こちらの要求でpreview0、HTTP失敗0。送信量の44%削減は実測で確定するが、遅延・欠落差を全てペイロード削減だけの効果と断定しない。軽量化しても中央値約26 msは変わらず、20 ms未達。歩行中は既存仕様でWebを休止するため、今回の改善が歩行中の画像遅延を直接短縮するとは言えない。

詳細→軽量→軽量→詳細の順でも、軽量時は約34 Hz、詳細時は約32.3〜32.5 Hzだった。p95も軽量43〜44.25 ms、詳細47.75〜50 msであり、通常表示時の負荷削減としてv35を採用する。キューdropは22〜29対27〜28で一貫した改善ではなく、画像サイズ不足や欠落自体は未解決。中央値の大幅短縮を達成したという結論にはしない。
