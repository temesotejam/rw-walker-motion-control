# 正側の実ZEROで加えた入力と次の到達エネルギー

新しい2走より前に同じ日に行った8走から、胴体が機械的な中心を正側へ通過したときの角速度・通電判断と、その次の正側ピークを組にした。先行する反対側ピーク以降に別の通電が入った場合、次のピークまで750 msを超えた場合、通電完了を確認できない場合は除いた。92件のうち、既存の正側電荷モデルの記録範囲13.27138 mA·sを超えた1件を除き、惰行27件・通電64件で係数を決めた。次のピークに到達できなかった運動は、この到達モデルの学習対象には含まれない。[抽出したイベントと実測値](right_arrivals.csv)

名目足裏形状で計算した次の正ピークの位置エネルギーを、`U右 [J] = 0.000152964 + 0.000465019 ω² + 0.0000934856 ωQ` で近似した。`ω` は機械的な中心を通過する角速度の大きさ [rad/s]、`Q` は指令幅、通電前の電流、電池電圧で変わる到達電流、立上り時定数を用いた既存の予測電荷 [mA·s]。床との接触力とホイールから胴体に伝わった実仕事は測定していない。係数を非負とし、同じ姿勢・速度の比較では予測電荷が増えると到達エネルギーも増えるようにした。走行を1本ずつ外して予測すると平均絶対誤差は0.571°。前の反対側ピークの位置エネルギーを説明変数に追加した場合は0.573°だったので、前のピーク角は適用範囲の確認に使った。[係数と検証の再計算](calibration.py)

実機の修正版では、±8°試験の起動目標が4.5°の間に限り、正側の通常ZEROで予定した幅を上限として、到達エネルギーが目標に最も近くなる整数ミリ秒を選ぶ。惰行指令は維持する。適用を前の負側ピーク2.13〜6.00°、角速度21〜51°/sに限定し、さらに角速度ごとに予測電荷の上限を課した。この上限からゼロまでの範囲は先行走行の角速度・予測電荷の組が張る凸包に含まれる。前倒しや同じ半周期の支持移行補助を含む場合は従来の判断を使う。小歩幅の比較用ボタンは元のv14式で動く。[機上の計算](../../src/right_arrival_energy.h)

## 新しい2走での照合

今回の2走は問題を見つけるために先に観察しており、係数を決めるデータからは外した。表の「実測」は以前の幅で実際に出たピーク、「新予測」はその以前の幅をモデルに入れた値。「変更候補」は同じ入力前状態で選び直した幅であり、その幅での実測は次の試験で行う。小歩幅の行は記録された状態に修正版の判断式を適用した比較である。1回目に通電が変化すれば、それ以後は実機の軌道も変わる。

| turn3・1.705秒 | 54 ms | 7.95° | 4.58° | 7.44° | 23 ms |

| turn3・3.469秒 | 43 ms | 7.80° | 4.62° | 6.94° | 18 ms |
| turn3・4.417秒 | 0 ms | 4.12° | 3.97° | 3.01° | 0 ms |
| turn3・5.217秒 | 28 ms | 7.15° | 4.62° | 5.51° | 18 ms |
| 小歩幅・1.544秒 | 50 ms | 7.20° | 4.56° | 7.70° | 18 ms |

元の通電4件での平均絶対誤差は2.93°から0.88°に下がった。元の惰行2件では0.32°から0.97°に増えた。合わせて6件で2.06°から0.91°。同じ記録済み指令に対する到達予測を比較した数値である。18 ms候補3件それぞれの近傍（角速度±3°/sかつ電荷±1 mA·s）に先行8走の通電例は0件、23 ms候補でも1件だった。短い幅の効果は惰行と長い通電の間の補間に依存する。修正後の到達ピーク、次の左への中心通過、反対足が出続けた時間、床上の前進量は実走で照合する。

保存したイベント表からは `python -B analysis/2026-11-20-ab-trials/calibration.py` で再計算できる。NumPyとg++を使い、係数を再推定した上で同じ機上C++を呼び出す。元のRWLOGから表を作り直すときは標準コンバーターで展開し、`--extract` に先行8走・今回2走の展開ディレクトリを指定する。[機上コードを呼ぶホスト側ツール](calibration.cpp)
