# turn2で数秒後に歩行が止まった2試行

両方の動画で左右の足が交互に前へ進み、立ったまま止まった。最後はいずれも、胴体が正側ピークから左へ向かう途中で速度を失い、次の左ピークを作れなかった。機体の測定と足角の更新は30秒まで続いた。RWLOGはともに目標±8°、`walking-support-transfer-v39-turn2`、CRC一致、FINISHEDである。

1走目の折り返しまでに取得した23画像はすべて両足とも有効だった。足角差が3°に届かないときに、足の形状からの補助が選ばれない条件があった。2走目では補助がすでに出ており、左足が支点になり得る時点と、追加の通電が実際に始まる時点を区別すると判定が変わった。両走行とも旋回による通常入力の増減は0件。前回turn1の同区間の前進量は約8.50小区画で、今回の2試行はいずれも短い。[床格子上の軌道と同期方法](video.md) · [通電と円弧の解析](energy.md)

turn3は左足に支持を戻す過程に限定して、これら2条件を改めた。再生で確認できるのは、同じ観測値を与えたときの入力の選択まで。通電を変えた後に胴体が左の円弧へ入り、右足が床上で前進して次の一歩につながるかは、次の試行のRWLOGと動画で確認する。[小さい足角差で減速する場合](gait.md) · [すでに通電している場合](energy.md)
