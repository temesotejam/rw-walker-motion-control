# turn1実走行52400264と次の制御

測定では両足が交互に前へ出たが、床格子で見た進路は4〜8秒の左10.8°から8〜12秒の左25.6°に曲がり、終盤は自立したまま足が止まった。5.269〜6.201秒の前振れ角は左10.45°、右1.12°で、相対ジャイロ方位が−22.16°変化した。続く周期では不足する足が入れ替わり、この一周期だけでは継続する偏りを判定できなかった。[外部動画の計測](video.md)

7.692〜9.502秒は二周期とも右足の前振れ・振れ幅が小さく、機体は同じ向きに回った。turn1は片方の周期の前振れ差1.65°が2°の判定値を下回ったため、ここでは補正できなかった。機上での初の旋回確定は15.377秒。最後の入力が戻り救済だったため、走行中の操舵による幅変更は0件だった。[足角度と仕事の再生](gait.md)

turn2を同じ記録に適用すると9.502秒で確定し、次の左右の通常入力は右足を出す側52→54 ms、左足を出す側42→41 msとなる。終盤の左への戻り補助では、前回ZEROを越えた後に受け足の円弧まで届かなかった角度を仕事に反映する。時刻と幅は各時点で実測した状態を用いた再生結果。次の実機走行で、実電流、左右交互の前進量、床上の進路、最後の支持移行を照合する。[戻り補助の再生](arc.md)
