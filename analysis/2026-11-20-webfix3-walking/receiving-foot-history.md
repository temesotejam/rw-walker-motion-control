# 同じ試行の過去の半周期から、受け足が戻る量を予測する

両試行で、受け足の150 ms先・250 ms先の角度は、同じ方向へ揺れた過去の半周期を参照すると平均絶対誤差（MAE）が小さくなった。戻りが成立した2回目5.251秒のように、履歴が少なく誤差が増える場面もあった。以下は保存ログ上の比較である。

| 試行・予測先 | カメラで照合できた枠 / 受け側の全枠 | 履歴あり / 照合可能（被覆率） | 同じ枠でのMAE、現行 → 履歴 | 履歴なしで現行に戻す場合の全照合枠MAE |
|---|---:|---:|---:|---:|
| 1回目・150 ms | 207 / 211 | 169 / 207（82%） | 1.75° → 1.14° | 1.58° → 1.08° |
| 1回目・250 ms | 206 / 211 | 111 / 206（54%） | 2.93° → 1.40° | 2.15° → 1.32° |
| 2回目・150 ms | 158 / 158 | 122 / 158（77%） | 2.03° → 1.31° | 1.82° → 1.26° |
| 2回目・250 ms | 155 / 158 | 71 / 155（46%） | 3.36° → 2.08° | 2.29° → 1.70° |

各時点で、現行方式では最新の足角・角速度を最大150 msまで等速で延長し、その先は姿勢を固定した。両足の±20°の外挿範囲も適用した。履歴方式では同じ試行の同方向の各半周期について、胴体ピークから同じ経過時間に始まる150 msまたは250 ms分の受け足変位を求め、その中央値を現在の足角に加えた。参照した半周期はすべて今回のピークより前に完結したものに限る。各変位の両端を同じ過去半周期内で観測でき、その画像が現在の判断までに制御器へ届いていることを確認した。通過成否による選別はしていない。

採点には改修版の再生で受け側（phase 2）だった全時点を使い、最後に折り返した半周期も含めた。正解は未来のカメラ撮影時刻に対応する有効なマーカー角で、前後の有効な画像が50 ms以内の間隔なら線形補間した。未来の観測は採点にのみ使用した。250 msのように同じ過去半周期に必要な長さが残っていない場合、履歴方式は値を返さない。照合枠内の各半周期に同じ重みを置いても、表の順でMAEは1.40° → 0.90°、2.40° → 1.33°、1.57° → 1.00°、2.86° → 2.01°になった。対象は順に31、23、23、16半周期である。

## 停止した戻りと、歩行が続いた戻り

| 判断時刻と実際の戻り | 予測先 | 現行 / 履歴 / カメラ測定 | 参照できた過去半周期 |
|---|---:|---:|---:|
| 1回目14.427秒・折返し | 150 ms | 6.05° / 5.35° / 3.97° | 18 |
| 同上 | 250 ms | 6.05° / 3.39° / 3.70° | 9 |
| 2回目5.251秒・ZERO通過 | 150 ms | 6.38° / 7.73° / 2.94° | 3 |
| 同上 | 250 ms | 6.38° / 算出不可 / 2.36° | 0 |
| 2回目10.828秒・折返し | 150 ms | 10.02° / 8.79° / 5.30° | 14 |
| 同上 | 250 ms | 10.02° / 5.59° / 2.89° | 4 |

6区間すべてで予測後の観測までにv19の通電があった。履歴ありの全照合枠でも、通電が重なったのは表1の順で117/169、101/111、67/122、58/71枠。新たな通電が重ならなかった枠だけのMAEもそれぞれ1.60° → 1.06°、2.91° → 1.69°、2.01° → 1.07°、2.24° → 1.31°だが、250 msのこの条件は10枠と13枠に限られる。どの結果にも過去の通電と残留電流の影響があり得る。別の通電方策での足角や、歩行が長く続くかは別の測定を要する。

## 再生成

2つのRWLOGを `tools/convert_rwlog_to_csv.py` で各測定ディレクトリに展開し、同じファイルをこのディレクトリの `replay_audit.py --out <再生結果>` に渡す。以下のコマンドはこのディレクトリから実行する。

```powershell
python -B compare_receiving_foot.py <1回目の展開先> <再生結果>/30307273-snapshots.csv
python -B compare_receiving_foot.py <2回目の展開先> <再生結果>/0efedf71-snapshots.csv
```
