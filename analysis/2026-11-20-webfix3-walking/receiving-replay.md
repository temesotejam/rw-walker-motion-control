# 足裏円弧の内端を越えるまでの再予測

2026年11月20日の2本の実歩行RWLOGについて、各時点で制御器に届いていた胴体・足・電流の値を、旧版と改修版のC++関数に同じ順序で与えた。ここで比較する終端は、受け側の足裏円弧の接点が内端を離れる胴体角である。実際の荷重や滑りは計測していない。

## 2回の停止と、戻りが成立した例

いずれも左足が前に出て、胴体は負方向へ戻っていた。3時点とも旧版は左足裏がすでに低いとして評価を終えた。改修版はその先に残るエネルギーを計算した。表の角速度の負号は、胴体では負側への移動、左足では前振れからの戻りを示す。

| 測定中の時刻 | 胴体角 / 角速度 | 左足角 / 左足の戻り速度 | 円弧の終端角 / 現速度での所要時間 | 惰性時の余裕 → 候補を加えた余裕 | 実機で起きたこと |
|---|---:|---:|---:|---:|---|
| 1回目 14.427秒 | +6.28° / −22.96°/s | +7.60° / −10.35°/s | −1.882° / 355 ms | −1.116 → −0.847 mJ（70 ms候補） | 12 ms通電。胴体は+1.07°まで戻って折り返した |
| 2回目 10.828秒 | +7.39° / −22.05°/s | +10.34° / −2.13°/s | −1.877° / 420 ms | −1.851 → −1.579 mJ（72 ms候補） | 27 ms通電。胴体は+0.45°で折り返した |
| 2回目 5.251秒 | +5.86° / −24.87°/s | +8.74° / −15.72°/s | −1.876° / 311 ms | −0.869 → −0.547 mJ（75 ms候補） | 18 msの通電後、5.446秒にZERO通過。そこから主入力が51 ms入り、5.515秒に終端を約36.4°/sで通過した |

3候補とも残存余裕が負で、開始時の速度は負方向の仕事モデルを校正した下限35.74°/sより小さかった。表の候補幅を実機に送った試行はない。2回目同士では、成功時のほうが左足が約7.4倍速く戻り、現速度で終端に達するまでの見積もりも約109 ms短かった。この1組から前進量や歩行の成功を判別するしきい値は決められない。1回目の14.427秒の取得枠は既存救済の判断と同じミリ秒にあり、旧版の演算結果が返ったのは約14.430秒で、実際の通電開始14.429秒より後だった。

## 全半周期での確認

| 比較対象 | 1回目 | 2回目 |
|---|---:|---:|
| 保存された判定枠 / キューで上書きされた枠 | 572 / 7 | 436 / 7 |
| 確認された胴体ピークから始まる半周期 | 37 | 29 |
| ZERO通過の記録または次の反対側ピークあり | 36 | 28 |
| 受け側の局面を評価できた半周期（最後の停止を含む） | 33 | 26 |
| 既存の初回通電判断とZEROより前に、校正範囲内の即時通電候補を得た半周期（受け側） | 0 | 0 |

最終行は、取得時点で出力ゲートが開き、当該半周期の通電前で、まだ元の側の胴体角にいる記録を対象とした。受け側で即時通電が候補になった9枠はいずれも負方向で、胴体速度の大きさは19.63〜31.48°/sだった。全1,008枠で旧版を再計算した理由・待機時間・幅は保存値と一致した。改修版の処理が実機でいつ完了するかはこのログからは分からない。

胴体が円弧終端を所定方向に5°/s以上で通るかを、IMUで初回の終端通過または折り返しまで追跡した。以下は取得からその瞬間まで追加の通電指令が入らず、時刻の連続性も確認できた枠に限る。観測開始時の残留電流はあり得る。

| 取得時の予測 → 実測 | 1回目 | 2回目 |
|---|---:|---:|
| 惰性で到達 → 実際に終端速度を確保 | 26枠・14半周期 | 38枠・11半周期 |
| 惰性で到達 → 終端前に折り返し | 1枠・1半周期 | 2枠・1半周期 |
| エネルギー不足 → 終端前に折り返し | 23枠・1半周期 | 18枠・1半周期 |
| エネルギー不足または通電候補あり → 追加通電なしで終端速度を確保 | 0枠 | 0枠 |

見逃した3枠は1回目の14.528秒と2回目の10.877、10.977秒で、いずれも終盤の救済通電が終わった後だった。2回目の10.877秒には救済終了から約12 msしか経っておらず、受け側に換算した開始電流は214 mA、加速度は約+677°/s²だった。その時点の勢いから終端まで惰性で届くと見積もったが、実際には途中で反転した。不足側の41枠も同じ2回の停止に集中している。各枠は独立した試行ではなく、既存の通電が入った区間の無通電時の成否は観察できない。

さらに、「惰性で到達」を連続2枠で確認したときだけ、その判定を確定扱いとする方法を調べた。同じ半周期・受け側・終端角でゲートが開いた隣接パケットを使い、2枠の間に通電指令が重なった場合や指令時刻が曖昧な場合は確定に含めなかった。折り返しを見逃した3枠はすべて暫定にとどまった。実際に終端速度を確保した64枠のうち、38枠（1回目12、2回目26）が確定し、26枠は暫定になった。正しく惰性で到達した25半周期のうち、一度以上確定できたのは13半周期だった。これは同じ2試行に対する事後評価で、確定率と待ち時間の兼ね合いは独立試行で検証する必要がある。

## 再現

リポジトリ直下で以下を実行する。CRC32を照合したRWLOGの監査表を使い、欠けた枠や実行後の映像から入力を補間しない。足裏の基準角は半周期内で順次更新した履歴から求める。RWLOGに格納された浮動小数点の桁数と、PCとESP32の数学関数の精度差が再現精度の限界となる。詳細CSVの `ready_after_us` と `old_ready_ms` は当時の旧版の実測である。

```powershell
py -B analysis/2026-11-20-webfix3-walking/replay_audit.py "$env:USERPROFILE/Downloads/energy_control_autonomous_run_1_69501075.rwlog" "$env:USERPROFILE/Downloads/energy_control_autonomous_run_2_224021399.rwlog" --out "$env:TEMP/walking_receiving_replay"
```
