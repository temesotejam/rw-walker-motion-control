# 床に対する移動と足角の対応

両試行とも最初の8秒はおおむねカメラの手前へ進んだ。左右足の白印の中点で測った手前方向の平均速度は、1回目が0.58小区画/s、2回目が0.57小区画/sだった。1回目の8〜16秒では、手前へ7.40小区画進む間に画面左にも1.47小区画移った。床格子上の平均進行方向は手前から左へ約11°で、これは胴体の向きを表す角度とは別に計算した。

| 試行・測定区間 | 手前への速度（小区画/s） | 画面右への速度（小区画/s） | 機体左 / 右の足角（°、各区間の95パーセンタイル） |
|---|---:|---:|---:|
| 1回目・0〜4秒 | 0.33 | 0.00 | 2.63 / 1.07 |
| 2回目・0〜4秒 | 0.30 | 0.00 | 1.92 / 1.21 |
| 1回目・4〜8秒 | 0.84 | +0.01 | 4.56 / 3.03 |
| 2回目・4〜8秒 | 0.83 | +0.04 | 3.68 / 3.11 |
| 1回目・8〜16秒 | 0.92 | −0.18 | 6.39 / 2.87 |

両試行で足の前振れが大きくなった区間に前進速度も上がった。一方、4〜8秒の前進速度はほぼ同じでも、左足の前振れは異なる。足角は歩幅・向きの変化を説明する候補であり、速度や進行方向との対応を一意に定めるには、左右交互の一周期に要する時間、足が戻る速さ、どちらの足にいつ荷重が移るかも効き得る。この2試行から特定の足角を与えたときに実現する速度や旋回角は決められない。

**研究での使い分け。** 接地とその次の同側接地を映像で確認できれば、その間の代表点の変位と所要時間から、一周期の前進速度と進行方向を評価できる。同じ周期で、左右足の最大前振れ・戻り速度、胴体の揺動速度・支持移行後の残速、通電時刻・幅・ホイール応答を照合する。これにより、目標速度・方向に対応する足運びを探し、その足運びを支える不足エネルギーを補う方策を検証できる。エネルギーはスカラーなので、入力の符号と左右どちらへ支持を移すかは別に保持する。

**計算方法。** [映像とIMUの同期・手前の床格子座標](video.md)を使い、有効な左右足の白印をそれぞれ床格子へ投影してから中点を取った。画面右向きの座標には幅12小区画離れた2本の格子線を使用した。画像の縦座標400、449、550 pxで、左線の横座標は487、474、448 px、右線は747、761、789 pxだった。各点の縦座標で両線の位置を線形補間（範囲外は端の傾きで延長）し、線間幅を12等分した。区間端では前後0.4秒の中点平均、開始位置では開始前0.8秒の平均を使った。表の足角はRWLOGの25 ms周期推定から求め、前振れを正とする。白印の高さと足の回転で床投影がずれるため、中点は床に対する移動の目安である。世界座標での重心速度・接触点の滑り・胴体のヨー角は直接測っていない。
