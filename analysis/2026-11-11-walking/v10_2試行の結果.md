# v10の2試行：連続歩行と足角度の遅延

2026-11-11。20:26:36の動画・run 2（137267573）と、20:28:46の動画・run 3（267557373）を比較した。元の動画とRWLOGは変更していない。

## 結論

前進する区間はあるが、両試行を安定した連続歩行の成功とは扱わない。左右揺動は測定終了近くまで続き、足の前振れには左右差と、揺動約2往復に対して前振れの山が1回となるパターンがある。以前のrun 27908524のような、終盤に中心を通れなくなる停止とは分ける。

今回のbuild IDは両方 `cad-support-shadow-v10`。追加した足予測・CAD計算は診断だけで、メタデータの `output_enabled=false`、`mapping_calibrated=false` を確認した。足が前に振れることで変わる支持切り替え位置に合わせた追加出力は、今回まだ実行していない。従ってこの2試行は、その介入の成否を調べた試験ではない。

白い機体マーカーの線分角とIMUの波形を合わせると、動画時刻−測定時刻はrun 2で約6.25秒、run 3で約6.70秒。これは機体運動による近似対応で、LED同期ではない。姿勢・投影・ゼロの違いによる角度差が残る。接地衝撃の因果判定に使える精度を保証しない。

## 足角度は遅れて届く

ユーザーから、足角度の認識処理が重く、角度が分かるまで時間がかかるとの再確認があった。受信した角度を現在の姿勢として扱わないことが必要。

| 記録時刻から求めた遅れ・中央値 | run 2 | run 3 |
|---|---:|---:|
| カメラドライバのフレーム時刻→画像受け取り | 50.37 ms | 50.42 ms |
| 足角度等の画像処理 | 12.45 ms | 12.38 ms |
| フレーム時刻→角度処理終了の概算 | 62.91 ms | 62.76 ms |
| フレーム時刻→制御側の最初の観測 | 77.66 ms | 77.17 ms |
| 同上95パーセンタイル | 87.67 ms | 88.25 ms |
| 足フレーム更新間隔 | 100.00 ms | 100.00 ms |

制御側観測は全296／298件中、間引いて保存された各64件を用いた。`foot_control_observations` は保存件数上限により `truncated=true`、ただし観測記録の照合失敗は0。最初に受け取った時刻の標本であり、その後同じ角度を再利用する時の全遅延を表さない。

「約63 ms」は予測計算を開始する頃までの経過時間で、制御側で使えるまでの全遅延ではない。またフレーム時刻はドライバの時刻で、実際の露光時刻との対応は未検証。モータの指令からトルクが発生する遅延も別にある。

v10は前回と今回のフレーム時刻の差から速度を計算し、取得遅れ約63 ms＋診断用30 ms、計約93 ms先へ外挿する。その点では画像処理遅延を無視していない。ただし次の100 msの画像更新までの経過時間や、実測したモータ応答まで含む介入用推定器にはなっていない。診断計算自体は予測可能なフレームで中央値約2.54／2.49 ms。

## 単純な直線外挿は、この2試行では有利でなかった

実際にログへ保存された予測値を、予測対象時刻の前後の有効カメラ値を線形補間した値と比較した。

| 比較 | run 2 | run 3 |
|---|---:|---:|
| 比較した左右角度の値の数 | 372 | 390 |
| 直線外挿の平均絶対差 | 0.400° | 0.429° |
| 直近角を保持した場合の平均絶対差 | 0.279° | 0.305° |
| 直線外挿の95パーセンタイル | 1.511° | 1.560° |
| 直線外挿の最大絶対差 | 2.378° | 3.058° |

足が前に振れて戻る山の付近では、直前区間の速度をそのまま延長すると、すでに減速・反転している動きから外れ得る。図でも山の先への過大外挿が見られる。従って「遅れる分だけ直線で先へ伸ばす」ことを介入版へそのまま採用しない。

これは独立した高速度カメラ等の角度真値との比較ではなく、同じ足認識器の将来値を補間した内部比較。保持値が一般に最良である、あるいは実際の誤差がこの値に収まる、と保証するものではない。

## 制御へ反映する方針

1. 足の観測値とそのフレーム時刻を組として扱う。遅れて到着した観測は、その過去時刻の推定状態を補正し、履歴にある機体角・角速度と足の運動状態を使って現在へ進める。出力判断時には、さらにモータ応答分の先を対象とする。
2. 前振れ中・頂点付近・戻り中を区別する。同じ機体角と角速度でも、今回の約2往復周期では足姿勢が異なり得るため、直近の足状態と周期の履歴も保持する。周期モデルを使う場合も、その時点までに得た履歴だけで更新する。
3. 推定した左右足姿勢と機体姿勢から、CAD上の支持高さ差と切り替え位置を求める。機体ゼロだけを介入基準にせず、引っかかりへ近づく位置とそこでの減速を判断に使う。カメラ角の絶対原点・CAD座標・前後姿勢の対応は未同定なので、現在のCAD根を実測の接地角とみなさない。
4. 位置に応じた入力の効果と、入力の大きさの効果を区別する。今回のログだけから必要な仕事量や何msの出力で越えられるかは決められない。最終評価は、支持が移り、次の足の前振れと前進が毎回続くこと。揺動の継続やゼロ通過回数だけでは判定しない。
