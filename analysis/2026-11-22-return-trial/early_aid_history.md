# 胴体が右+4.5°まで戻ったとき、左補助を前倒しできるか

最新3走を追加し、既存の+4.5°警報を「その右ピークからまだ左補助を使っていない半周期」で再評価した。比較したのは、過去に補助が入った後の状態も参考にする既存の方法と、過去例も同じ通電履歴に限定する方法。入力は同じ時点で利用できた胴体速度、過去約25 msの速度変化、足角差。過去の異なる3走から近い1区間ずつを選ぶ。3例目の距離は既存の四分位範囲1以内、2例以上が中心手前で折り返したら警報とした。

| +4.5°観測後、次の中心通過または折返しまで追加通電がない半周期 | 自力で通過／折返し | 既存の方法の誤警報／折返し検出 | 過去例も補助未使用に揃えた場合の誤警報／折返し検出 |
|---|---:|---:|---:|
| 11月20日先行8走、各走を1本ずつ除外 | 83 / 1 | 0 / 0 | 0 / 0 |
| 11月20日後続2走、先行8走を固定 | 1 / 1 | 0 / 1 | 0 / 0 |
| 11月22日3走、同じ先行8走を固定 | 7 / 1 | 0 / 1 | 0 / 0 |

195727101の3.901秒では、既存の方法が実測の折返しより約167 ms早く警報を出す。現在の足裏予測による開始候補3.977秒より76 ms早い。既存の3例は「補助なしで折返し」「補助なしで通過」「すでに左補助を出してから折返し」。最後の1例を通電履歴も揃えて選び直すと、別の走行で自力通過した例に変わり、多数決が逆転した。先行8走で入力履歴を揃えて参照できる折返しは1走1件である。過去例の選び方によっては今回の失敗に早く気付けるが、この時点で通電を確定できるほど事例は揃っていない。

また、195727101の同じ時点で21 ms通電を即時に開始した例に近い通電は2走2件。25・50・75 ms後から開始する案に近い事例は0件だった。局所モデルは惰性でも+2.59°へ到達すると推定したが、実機は+2.81°で折り返した。未通電の軌道を再現できていないため、これらの推定値で最適な開始時刻は決められない。[候補時刻の比較](README.md)
